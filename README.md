# FFXIV DataMining HexCode Mixed

本项目是使用 [XivExdUnpacker](https://github.com/Souma-Sumire/XivExdUnpacker) 工具生成的《最终幻想 14》（FINAL FANTASY XIV）多语言游戏数据导出集合。所有数据均以 **HexCode** 格式导出。

## 数据版本

本项目的数据采集与追踪始于以下版本：

| 客户端类别 | 包含目录 | 起始记录版本 |
| :--- | :--- | :--- |
| **国服 & 国际服** | `chs`, `en`, `ja`, `de`, `fr` | 7.40 |
| **韩服 (KO)** | `ko` | 7.35 |
| **繁中服 (TC)** | `tc` | 7.0 |
